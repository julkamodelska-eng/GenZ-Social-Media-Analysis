# Gen Z Social Media Analysis

## Project Overview
This project analyzes Gen Z social media usage patterns using SQL Server and Power BI.

## Tools Used
- SQL Server Management Studio
- Power BI
- GitHub

## Key Questions
- Which social media platforms are most popular among Gen Z?
- How does social media usage differ by gender and age?
- What are the main purposes of social media usage?
- Is there a relationship between night usage and mental health score?

## Files
- `SQL_queries.sql` – SQL queries used for data exploration and analysis
- `PowerBI_dashboard.pdf` – exported Power BI dashboard
- `dashboard_screenshot.png` – dashboard preview

## Key Insights
- Instagram is the most popular platform among users.
- Entertainment is the main purpose of social media usage.
- Users aged 18 and 22 show the highest average session duration.
- Night usage does not significantly affect average mental health scores.

## Data Source
Dataset: Gen Z Social Media Usage Dataset from Kaggle.
